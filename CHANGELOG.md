# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-14

### Added

- Quick Settings brightness slider for the monitor, with GNOME's brightness OSD.
- GameVisual mode menu (locked while HDR is on, where the monitor ignores it).
- HDR toggle that changes only this monitor's color mode and keeps the rest of the layout.
- HDR preset menu (Cinema, Gaming, Console, DisplayHDR 500 True Black), shown while HDR is on.
- Dynamic Brightness Boost switch, shown in Console HDR.
- Brightness keys follow the pointer: this monitor when the pointer is on it or there is
  no built-in panel, the built-in panel otherwise. A preferences switch hands them back to GNOME.
- <kbd>Super</kbd>+<kbd>Alt</kbd>+<kbd>H</kbd> toggles HDR.
